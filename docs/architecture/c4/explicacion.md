# E7 — Explicación para público no técnico (borrador, menos de 120 palabras)

BiblioUNSA permitirá que los estudiantes consulten qué libros están disponibles y soliciten reservas. Los bibliotecarios podrán registrar los préstamos, recibir devoluciones y gestionar retrasos. Para comprobar si una persona puede reservar, el sistema consultará la matrícula vigente en el sistema académico de la UNSA. También utilizará la identificación institucional para controlar el acceso. Esta separación ayuda a que la biblioteca maneje sus libros sin tener acceso directo a los datos internos del sistema académico.
