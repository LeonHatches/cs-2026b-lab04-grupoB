## Anexo: prompts completos

### Interacción 1

Ayúdanos a completar el archivo agentes/diseno/lienzo.md para nuestro sistema agéntico del proyecto BiblioUNSA. Desarrolla las 7 decisiones de diseño del Paso 2, explicando cada decisión y su justificación. Considera el tipo de agente, las herramientas disponibles, el modelo de coordinación, la memoria, las restricciones, el nivel de autonomía y la forma de evaluar sus resultados. Propón un agente ReAct que pueda trabajar con issues del repositorio. Si alguna tarea se resuelve mejor mediante un flujo fijo que mediante un agente, indícalo y justifica por qué. No propongas funcionalidades innecesarias ni permisos que no sean requeridos para el caso.

### Interacción 2

Ayúdanos a definir 3 issues para evaluar nuestro sistema agéntico del proyecto BiblioUNSA. Para cada issue, genera el .md que incluya el problema observado, el resultado esperado y una prueba objetiva que permita reproducir el error. Considera errores relacionados con validaciones, generación de criterios de aceptación y consultas SQL. También genera las pruebas correspondientes en tests/, procurando que cada prueba falle inicialmente por el error descrito y que posteriormente permita verificar su corrección. No inventes resultados de ejecución y asegúrate de que las pruebas sean verificables.

### Interacción 3

Diseña la máquina de estados de nuestro agente ReAct para el proyecto BiblioUNSA utilizando PlantUML, tomando como base la máquina de estados del laboratorio. Incluye los estados Inicio, Planificación, Ejecución de herramienta, Observación, Validación, Finalización y Error, así como las transiciones correspondientes. Considera qué sucede cuando una herramienta devuelve un resultado válido, cuando ocurre un error, cuando la respuesta no cumple el contrato o cuando se necesita repetir una acción. Asegúrate de que el agente no pueda pasar directamente de Ejecución a Finalización sin validar previamente el resultado. Entrega el código listo para guardarlo en agentes/diseno/estados.puml.

### Interacción 4

Propón e implementa una herramienta adicional para nuestro agente ReAct que le permita resolver de manera más eficiente los issues 2 y 3 del proyecto BiblioUNSA. Considera herramientas como mapa_repo(), que permita inspeccionar la estructura de archivos y obtener las firmas de funciones, y un sistema de memoria de notas mediante anotar(texto) y leer_notas() para guardar hipótesis, archivos revisados y hallazgos. Explica cómo registrar estas herramientas en catalogo(), qué argumentos y resultados deberían tener y qué pruebas se deben agregar. Considera que la herramienta debe trabajar con información real del repositorio y que el agente no debe inventar archivos, funciones ni resultados. 

### Interacción 5

Define la delegación progresiva y los cuatro roles humanos de nuestro sistema agéntico en delegacion.md: ejecutor, revisor, colaborador y gobernador. Para cada rol, establece sus responsabilidades, permisos, acciones que puede autorizar o rechazar y el nivel de autonomía permitido al agente. Define qué evidencias obtenidas de las trazas, pruebas y resultados de ejecución justificarían pasar de una etapa de delegación a otra. Considera que las modificaciones al código deben requerir aprobación humana cuando corresponda y que el agente no debe poder aprobar sus propias acciones. Presenta la información de forma clara y aplicable a nuestro proyecto.
